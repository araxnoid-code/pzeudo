##### 0.0.3-dev.1-no_update
_12 Aug 2026_
- Added an update property to ParamsStorage and GradStorage.
- The update property serves as a flag indicating whether the corresponding gradient has been updated.

- Added an is_update method to ParamsStorage and GradStorage.

- Renamed the function check_no_grad_or_time_not_match to is_no_grad_or_time_not_match_or_no_update. 
  - The addition of '_or_no_update' to the function name reflects the change in functionality: it now also checks whether the gradient has been updated. 
  - The names of the functions GradStorage::check_no_grad and GradStorage::check_time_not_match were also updated by replacing 'check' with 'is'.

_12 Aug 2026_
- Added methods:
  - GradStorage
    - GradStorage::set_update
  - ParamsStorage
    - ParamsStorage::set_update
  - ArrayStorage
    - ArrayStorage::set_grad_update

- Updated arithmetic operation backward passes: the update status of the relevant gradient is now set to 'true' after the backward function executes.

- Changed the record structure to `Vec<Option<RecordLabel<F>>>`.

- Added the RecordStatus enum.

- Added the record_status property with the data type Option<RecordStatus>:
  - record_status is used to mark specific indices in the record where the connection should be severed during the backward phase. 
  - record_status and the update status work in tandem; when a record connection is severed, the update status of the associated gradient remains unchanged. Gradients with an update status of 'false' are skipped, eliminating the need for gradient calculations if the parent gradient's connection has already been severed.

- Currently undergoing adjustments due to fundamental structural changes.

_12 Aug 2026_
- The activation function has been adjusted to include record_status.

- The view method has been adjusted to include record_status.

- The unary method has been adjusted to include record_status.

- Matmul 2D and Matmul ND have been adjusted to include record_status.

- 2D arithmetic and Matmul nD have been adjusted to include record_status.
