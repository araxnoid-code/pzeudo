### Changelog
_06 Sep 2026_
- Create the 0.0.4 plan.

- update version.md, README.md and project version

_06 Sep 2026_
- initialization changes to Arrays 
  - changed the Array::from_vector_with_shape method which previously accepted slices to now accept vectors. 
  - added method Array::from_slice_with_shape which allows creating arrays using slices. 
    - Changes in array initialization cause changes to tensor initialization and related methods. 
      - Tensor Initialization 
        - changes Tensor::from_vector_with_shape will now accept vectors 
        - changed Tensor::param_from_vector_with_shape will now accept vectors 
        - added Tensor::from_slice_with_shape 
        - added Tensor::param_from_slice_with_shape 
      - Methods and functions related to initialization changes to Arrays have been updated 
      - code tests related to initialization changes to Arrays have been updated

_06 Sep 2026_
- change the Tensor initialization method below 
  - Method that has changed. 
    - Tensor::ones 
    - Tensor::from_slice_with_shape 
    - Tensor::from_vec_with_shape 
  - Tensor::from_array 
    - The change that occurs is changing the data type parameters from ModuleBuilder to Module. This was changed to allow creating tensors inside epochs.

_06 Sep 2026_
- Initialization mechanisms have changed:
  - Parameter tensors can only be initialized outside of an epoch because they require a ModuleBuilder.
    - These tensors are not cleared at the end of each epoch. 
  - Non-parameter tensors can be initialized either outside or inside an epoch, as they require a Module. 
    - Initializing them outside an epoch can be risky because non-parameter tensors in the storage array are cleared at the end of each epoch; therefore, it is safer to initialize them inside an epoch or designate them as parameters if the tensor is important.

_06 Sep 2026_
- Added tensor operations:
  - Methods
    - Tensor::add_scalar, Tensor + scalar
    - Tensor::scalar_add, scalar + Tensor
    - Tensor::sub_scalar, Tensor - scalar
    - Tensor::scalar_sub, scalar - Tensor
  - Backward
    - Added the add_scalar_backward function
      - Tensor::add_scalar and Tensor::scalar_add both use the same backward function: add_scalar_backward.
    - Added the sub_scalar_backward function
    - Added the scalar_sub_backward function

_7 Sep 2026_
- Added tensor operations:
  - Methods
    - Tensor::mul_scalar, Tensor * scalar
    - Tensor::scalar_mul, scalar * Tensor
    - Tensor::div_scalar, Tensor / scalar
    - Tensor::scalar_div, scalar / Tensor
  - Backward
    - Added the mul_scalar_backward function
      - Tensor::mul_scalar and Tensor::scalar_mul both use the same backward function: mul_scalar_backward.
    - Added the div_scalar_backward function
    - Added the scalar_div_backward function

- Fixed bugs in tensor scalar operations
  - Fixed bugs in sub_scalar_backward and added scalar_sub_backward due to incorrect RecordLabel usage
  - Fixed bugs in sub_scalar_backward, scalar_sub_backward, and add_scalar_backward due to incorrect indexing of the gradient array

_7 Sep 2026_
- Added a softmax + cross-entropy loss function named softmax_cross_entropy
  - Added the softmax_cross_entropy_backward function
  - softmax_cross_entropy_backward can now be used for backpropagation

_7 Sep 2026_
- Update to softmax_cross_entropy
  - Added documentation for softmax_cross_entropy and softmax_cross_entropy_backward
  - Added shape validation for softmax_cross_entropy

_8 Sep 2026_
- Added a new boolean property named contiguous to ArrayRef and ArrayRefMut.
  - This new property serves as an additional validation check—alongside the Contiguous and View types, for performing indexing.
  - Implemented in ArrayTrait::linear_index.
  - Implemented in ArrayAssignTrait::linear_index.

_8 Sep 2026_
- Updates to WeightInit
  - WeightInit::He has been split into WeightInit::HeIn and WeightInit::HeOut
    - WeightInit::HeIn uses in_features

  - Added WeightInit::Custom(mean, std_dev)
    - WeightInit::Custom allows for manual configuration of mean and std_dev

_8 Sep 2026_
- changed the parameter data type of Array::from vector which originally accepted slices to now accept vectors directly.

_16 Sep 2026_
- BatchNorm Update
  - Added channel_size property to batch_norm
  - Added momentum property to BatchNorm
    - Default value = 0.1
  - Added tensor input validation
    - Can only accept tensors > 1 dimension
    - dim input tensor > channel index

    - Running avg and running var will be used in the evaluation phase
