#### 0.0.2-dev.2-take_replace
_9 Aug 2026_
- Fixed an bug where the ArrayStorage::get_grad_storage_mut method was incorrectly returning ArrayStorage

- Added mechanisms to take and replace gradients for:
  - GradStorage
    - GradStorage::take_grad
    - GradStorage::replace_grad
  - ParamsStorage
    - ParamsStorage::take_grad
    - ParamsStorage::replace_grad
  - ArrayStorage (as an API combining GradStorage and ParamsStorage)
    - ArrayStorage::take_grad
    - ArrayStorage::replace_grad

- Conducted tests using add_backward to verify this take-and-replace functionality.

_9 Aug 2026_
- implement ArrayStorage::take_grad and ArrayStorage::replace_grad in
  - sub_backward
  - div_backward (not yet complete)

- Added the TakeType enum with the following fields:
  - TakeType::Array
  - TakeType::Metadata

- Added new methods to ViewStorage:
  - ViewStorage::take_metadata
  - ViewStorage::replace_metadata

- Modified ArrayStorage::take_grad to return TakeType, enabling the retrieval and replacement of Metadata. 
  - With both Array and Metadata options available, it is now possible to construct an ArrayRef from TakeType using the TakeType::to_array_ref method. This is crucial for handling all possible scenarios and adding flexibility to take and replace operations. 
  - All functions utilizing ArrayStorage::take_grad prior to this update have been adjusted to accommodate this change.

- Modified ArrayStorage::replace_grad to accept TakeType. 
  - All functions utilizing ArrayStorage::replace_grad prior to this update have been adjusted to accommodate this change.
