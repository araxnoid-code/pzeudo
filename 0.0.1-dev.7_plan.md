##### 0.0.1-dev.7-storage
_26 july 2026_
- Changes to ArrayStorage
  - ArrayStorage now has three components
    - permanent_storage: used to store array pairs (array as value and array as grad) that are not intended for deletion.
    - arr_storage, of type ArrStorage, used to store value values ​​(array or view).
    - grad_storage, of type GradStorage, used to store grad values ​​(array).
  - Internal changes to the ArrayStorage method, but almost all of them do not interfere with the method's use by other code.
    - name changes and additions to the ArrayStorage method 
      - name change 
        - ArrayStorage::get_arr_storage 
        - ArrayStorage::get_arr_storage_mut 
        - ArrayStorage::get_permanent_storage 
        - ArrayStorage::get_permanent_storage_mut 
        - ArrayStorage::get_arr_element_mut 
      - addition 
        - ArrayStorage::get_grad_storage 
        - ArrayStorage::get_grad_storage_mut 
        - ArrayStorage::get_grad_element_mut 
      - Internal Changes 
        - ArrayStorage::get_as_array_ref 
        - ArrayStorage::get_as_array_ref_mut

_27 july 2026_
- Updates to ArrayStorage
  - ArrayStorage now stores array types completely separately.
    - view_storage
    - arr_storage
    - grad_storage
    - permanent_storage
  - changes to the ElementType enum, which now has 3 fields and no longer stores ContiguousType:
    - Arr
    - Grad
    - View
  - Removed useless (or still unusable) methods in ArrayStorage
    - ArrayStorage::remove
    - ArrayStorage::get_element
      - Removed the GetElementOutput enum
    - ArrayStorage::get_element_mut
      - Removed the GetElementMutOutput enum
  - Added the ViewStorageType enum, which has 2 fields:
    - Storage
    - Permanent
  - Changes to TensorMetadata, adding the array_index property of type ViewStorageType.
  - Changes to the ArrayStorage::get_as_array_ref and ArrayStorage::get_as_array_ref_mut methods due to structural changes.
  - Gradient can now be retrieved using ArrayRefMut<'_, View>
  - Backward methods (add_backward, sub_backward, etc.) now use the View type of ArrayRef or ArrayRefMut to access the right or right side of a gradient.
  - methods that still use ArrayStorage in the old way have been adjusted.

##### 0.0.1-dev.7-view
_27 july 2026_
- Added ArrayRefMut::to_ones method

- Updated Tensor::view method, which can now be used backward.

- Renamed OpsSlicing method to OpsSlice, and renamed slicing method to slice.

- Added tensor operation views, including:
  - Tensor::slice
  - Tensor::broadcast

- Changed the Tensor::backward mechanism. Now the gradient is added to 1 instead of 1. This allows the broadcast to continue its gradient without additional operations.
  - Therefore, it requires a gradient condition of 0 from the start to run backward.

- Changes to tensors
  - Added one property to tensors, namely shape.
  - Changed the parameter of the Tensor::new method, which now has the same data type as the tensor property itself.

_28 july 2026_
- Added view methods to tensors:
  - Tensor::permute
    - Added testing code for permute (simple case)
  - Tensor::t
  - Tensor::index
  - Tensor::to_shape
  - Tensor::reshape
