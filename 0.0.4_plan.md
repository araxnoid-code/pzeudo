_06 Sep 2026_
- initialization changes to Arrays 
  - changed the Array::from_vector_with_shape method which previously accepted slices to now accept vectors.

        - added Tensor::param_from_slice_with_shape

_06 Sep 2026_
- change the Tensor initialization method below 
  - Method that has changed. 
    - Tensor::ones 
    - Tensor::from_slice_with_shape 
    - Tensor::from_vec_with_shape 
  - Tensor::from_array 
    - The change that occurs is changing the data type parameters from ModuleBuilder to Module. This was changed to allow creating tensors inside epochs.

_06 Sep 2026_
- Initialization mechanisms have changed:
  - Parameter tensors can only be initialized outside of an epoch because they require a ModuleBuilder.
    - These tensors are not cleared at the end of each epoch. 
  - Non-parameter tensors can be initialized either outside or inside an epoch, as they require a Module. 
    - Initializing them outside an epoch can be risky because non-parameter tensors in the storage array are cleared at the end of each epoch; therefore, it is safer to initialize them inside an epoch or designate them as parameters if the tensor is important.

_06 Sep 2026_
- Added tensor operations:
  - Methods
    - Tensor::add_scalar, Tensor + scalar
    - Tensor::scalar_add, scalar + Tensor
    - Tensor::sub_scalar, Tensor - scalar
    - Tensor::scalar_sub, scalar - Tensor
  - Backward
    - Added the add_scalar_backward function
      - Tensor::add_scalar and Tensor::scalar_add both use the same backward function: add_scalar_backward.
    - Added the sub_scalar_backward function
    - Added the scalar_sub_backward function
